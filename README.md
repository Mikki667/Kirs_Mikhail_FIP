# Mikhail Kirs – Portfolio Website  

## Overview
This portfolio website showcases my work as a **web developer and video editor**. It highlights my projects, technical skills, and creative work in a clean, modern, and easy-to-navigate design.  

The goal of this project is to present my capabilities in **web design, development, and video editing**, while also serving as a personal brand platform where visitors can learn more about me and get in touch.  

## Features
- **Responsive design** – optimized for desktop and mobile.  
- **Project gallery** – each project includes images, descriptions, and key details.
- **About Me section** – personal and professional background.  
- **Video reel** – a short showcase of my editing and motion work.    
- **Contact form** – allows visitors to send messages directly or connect through social links.  

## Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript, SASS  
- **Backend:** PHP  
- **Database:** MySQL  
- **Version Control:** Git & GitHub  
- **Video Tools:** Adobe Premiere Pro, Adobe After Effects  
- **Design Tools:** Adobe Illustrator, Figma  

## Structure
The website consists of four main pages:
- **Home:** Welcome video and navigation to main sections.  
- **About Me:** Information about my skills, experience, and interests.  
- **Projects:** A collection of my best web and video projects.  
- **Contact:** Contact form and links to my social media profiles.  

All pages share a consistent layout with a fixed header and footer for intuitive navigation.  

## Purpose
This portfolio was created to:
- Present my work to potential employers and collaborators.  
- Demonstrate my technical and creative abilities.  
- Serve as a central hub for my professional identity online.  

## Future Improvements
